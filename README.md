# HW2 — Netflix Hit Predictor

Course assignment: integrate Netflix Top 10 viewing data with IMDb and TMDb metadata, engineer features, define a HitScore, and train a classifier to predict Hit / Not Hit.

- `netflix.ipynb` — analysis and modeling notebook
- `studentID_netflix_report.docx` — written report
- `data/netflix.titles.composite.csv` — core table (Netflix Top 10 with pre-matched IMDb/TMDb fields)

## Data not included

`data/imdb.titles.composite.csv` and `data/tmdb.titles.v3.csv` (~75MB each) are not in this repo. They are course-provided TV-series metadata derived from IMDb and TMDb; place them in `data/` to run the notebook.
